ভূমি ও ফ্ল্যাট পরিমাপের বিস্তারিত হিসাব

কাঠার হিসাব

  • ১ কাঠা = ৭২০ বর্গফুট
  • ১ কাঠা = ৮০ বর্গগজ
  • ১ কাঠা = ১.৬৫ শতাংশ
  • ১ কাঠা = ১৬ ছটাক
  • ২০ কাঠা = ১ বিঘা
  • ৬০.৫ কাঠা = ১ একর

একরের হিসাব

  • ১ একর = ১০০ শতাংশ (শতক)
  • ১ একর = ৩ বিঘা ৮ ছটাক
  • ১ একর = ৬০.৫ কাঠা
  • ১ একর = ৪,০৪৭ বর্গমিটার
  • ১ একর = ১০ বর্গ চেইন

বিঘা ও কাঠার হিসাব

  • ১ বিঘা = ১৪,৪০০ বর্গফুট
  • ১ বিঘা = ১৬০০ বর্গগজ
  • ১ বিঘা = ২০ কাঠা
  • ১ বিঘা = ৩৩ শতাংশ
  • ১ বিঘা = ৬৪০০ বর্গহাত (৮০ হাত × ৮০ হাত)

শতাংশ, অযুতাংশ ও ছটাক

  • ১ শতাংশ = ৪৩৫.৬ বর্গফুট
  • ১ শতাংশ = ১০০ অযুতাংশ
  • ৫ শতাংশ = ৩ কাঠা (১৩০৬.৮ বর্গফুট)
  • ১ অযুতাংশ = ৪ বর্গফুট ৫২.৩৬ বর্গ ইঞ্চি
  • ১ ছটাক = ৪৫ বর্গফুট
  • ১ ছটাক = ২০ গন্ডা

চট্টগ্রামের স্থানীয় পরিমাপ (কানি ও গন্ডা)

কানি দুই প্রকার: (ক) কাচ্চা কানি (৪০ শতকে ১ কানি) এবং (খ) সাই কানি (১২০ বা ১৬০ শতকে ১ কানি)।

কানি ও গন্ডার হিসাব

  • ১ কানি = ১৬,৯৯০ বর্গফুট (ক্ষেত্রবিশেষে ১৭,২৮০ বর্গফুট)
  • ১ কানি = ৩৯ শতাংশ (প্রায়)
  • ১ কানি = ২৩.৫ কাঠা
  • ১ কানি = ২০ গন্ডা
  • ১ কানি = ১৯৩৬ বর্গগজ / ১৬১৯ বর্গমিটার / ৪০ বর্গ লিঙ্ক
  • ১ গন্ডা = ২ শতাংশ / ১.২১ কাঠা / ৮৬৪ বর্গফুট
  • ২ কানি ১০ গন্ডা = ১ একর (৪০ শতকের কানিতে)

প্লট ও ফ্ল্যাটের ব্যবহারিক পরিমাপ

প্লটের পরিমাপ

  • ৩ কাঠার প্লট = ২১৬০ বর্গফুট
  • ৫ কাঠার প্লট = ৩৬০০ বর্গফুট
  • ১০ কাঠার প্লট = ৭২০০ বর্গফুট
সতর্কতা: রাজউক (RAJUK) ইমারত নির্মাণ আইন অনুযায়ী, রাস্তা, ড্রেন এবং আলো-বাতাসের জন্য মোট জমির এক-তৃতীয়াংশ জায়গা খালি রাখতে হয়।

রেডি ফ্ল্যাট কেনার হিসাব

ফ্ল্যাট বিক্রয়কারী প্রতিষ্ঠানগুলো সিঁড়ি, সামনের ও পেছনের খালি জায়গাও মোট আয়তনের অন্তর্ভুক্ত করে থাকে। তাই মূল (Net) আয়তন সাধারণত কম হয়:

  • ৯০০ বর্গফুটের ফ্ল্যাট মূল আয়তন: ৬০০ - ৬৫০ বর্গফুট
  • ১২০০ বর্গফুটের ফ্ল্যাট মূল আয়তন: ৭৮০ - ৮৫০ বর্গফুট
  • ১৬০০ বর্গফুটের ফ্ল্যাট মূল আয়তন: ১২০০ - ১২৫০ বর্গফুট
