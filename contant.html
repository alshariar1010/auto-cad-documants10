১. বেসিক পেজ এবং লেয়ার সেটআপ (Page & Layer Setup)

Page Setup (পেজ সেটআপের ধাপসমূহ):

  1. Units Setup (UN ↵): কীবোর্ডে UN লিখে এন্টার দাও। Length Type থেকে 'Architectural' বা 'Engineering' (ফিট/ইঞ্চির জন্য) অথবা 'Decimal' (মিলিমিটার/মিটারের জন্য) সিলেক্ট করো। Precision 0'-0" বা 0.00 রাখো।
  2. Limits (LIMITS ↵): LIMITS লিখে এন্টার। Lower left corner: 0,0 ↵। Upper right corner: তোমার প্রজেক্টের সাইজ অনুযায়ী (যেমন: 100',100') দিয়ে ↵ দাও।
  3. Zoom All (Z ↵ A ↵): লিমিট সেট করার পর পেজটিকে স্ক্রিনে ফিট করতে Z এন্টার, তারপর A এন্টার দাও।
  4. Dimension Style (D ↵): D লিখে এন্টার দিয়ে Modify-তে যাও। 'Primary Units' এ গিয়ে পেজ ইউনিটের মতো সেম ইউনিট সেট করো। 'Text' এবং 'Symbols and Arrows' ট্যাব থেকে টেক্সট ও অ্যারো সাইজ (যেমন: 6" বা 8") ঠিক করে Set Current এ ক্লিক করো।

Layer Setup (লেয়ার সেটআপ):

সিভিল ড্রয়িংয়ে প্রফেশনাল কাজের জন্য লেয়ার অত্যাবশ্যক। কমান্ড: LA ↵

  • নতুন লেয়ার তৈরি করতে Alt + N চাপো অথবা 'New Layer' আইকনে ক্লিক করো।
  • কাজের সুবিধার্থে আলাদা লেয়ার বানাও: Wall, Window, Door, Column, Stair, Text, Dimension, Hatch।
  • প্রতিটি লেয়ারের জন্য আলাদা Color (যেমন: ওয়ালের জন্য সায়ান, কলামের জন্য ম্যাজেন্টা) এবং Line Weight (ওয়াল 0.25mm, কলাম 0.30mm) সেট করো।
